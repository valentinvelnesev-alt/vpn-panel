## 🆕 Добавлено

- **Клиенты бота** — новый раздел панели: поиск по Telegram ID / @username, баланс, подписки, история операций и покупок.
- **Начисление и списание баланса** вручную с обязательной причиной; операция попадает в историю, клиенту (по желанию) приходит уведомление.
- **Персональные тарифы** — в карточке клиента: своя цена, срок, сквады, лимит устройств и трафика. Видны в боте только этому клиенту, сверху списка со ⭐.
- **Скидка на все тарифы** (Бот → Скидка): процент и необязательная дата окончания. В боте старая цена зачёркнута, рядом новая. На персональные тарифы не действует; со скидкой по промокоду не складывается — берётся большая.
- **Скрытие кнопок меню бота**: Поддержка/помощь, Промокод, Мой профиль, Баланс, История покупок, Мои подписки, Пригласить друга, Канал, Пробный период, команда /help.
- **Режим «одна подписка на клиента»** (по умолчанию) или «несколько подписок» с кнопкой «Купить ещё одну».
- **Проверка чата продаж** кнопкой «Проверить» — тестовое сообщение и понятное объяснение ошибки Telegram. Можно указать @имя публичной группы.
- **Тестовая рассылка себе** — увидеть фото, подпись, кнопки и разметку до отправки всем.
- **Название и логотип панели** (Настройки → Название панели). По умолчанию вкладка называется нейтрально — «Panel».
- **Секретный путь панели** (`PANEL_SECRET_PATH`): без него сервер отвечает пустым 404. Новые установки получают его автоматически.
- **2FA** (Настройки → Безопасность) с QR-кодом, **«Выйти везде»**, **блокировка IP** на 15 минут после 10 неудачных входов.

## 🐛 Исправлено

- Клиент с подпиской видел «Купить подписку», и оплата заводила второй ключ вместо продления. Теперь: нет подписки — «Купить», есть — «Продлить подписку».
- Скидка из промокода обещалась в боте, но нигде не применялась — теперь применяется к следующей оплате.
- Уведомления о продажах в группу молча терялись: не было продлений и автопродлений, а при превращении группы в супергруппу id менялся. Теперь шлются все виды продаж, новый id подхватывается автоматически.
- Рассылка с фото: файл отправляется напрямую с сервера (раньше Telegram должен был скачать его по ссылке, что не работало за файрволом / по IP). Подпись длиннее 1024 символов больше не «съедает» всю рассылку — панель предупреждает заранее. При лимитах Telegram получатель не теряется, а отправка повторяется.
- Рассылка могла уйти дважды, а пока она шла, бот не реагировал на «Остановить» и подтверждения оплат.
- Одна оплата могла выдать подписку дважды (вебхук + проверка + фоновые воркеры одновременно).
- Двойное нажатие «Из баланса» могло увести баланс в минус.
- Сбой Remnawave при оплате с баланса списывал деньги без выдачи подписки — теперь списание откатывается.
- Автопродление: сбой у одного клиента откатывал списания у всех продлённых до него (подписка при этом оставалась продлённой).
- Напоминания об окончании подписки могли остановиться на первом дубликате.
- Пробный период мог перезаписать платную подписку триальными серверами.
- Оплата удалённого/выключенного тарифа (Stars, внешние кассы) больше не теряется — подписка выдаётся, либо деньги зачисляются на баланс.
- Реферальная комиссия при оплате Stars приходила в уведомлении дважды.
- Подтверждение оплаты/рассылки из панели доходило до бота раньше записи в базу — выдача задерживалась до минуты.
- `update.sh` не делал бэкап базы (неверные имя пользователя и базы) и не применял изменения конфига Caddy.
