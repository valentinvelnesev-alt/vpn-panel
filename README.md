## Что это

Вы держите VPN на [Remnawave](https://github.com/remnawave), продаёте доступ через
Telegram-бота и хотите управлять всем этим из одного места — без ssh, без правки
конфигов руками. VPN Panel даёт веб-панель с дашбордом, управлением нодами и
пользователями, и Telegram-бота, который подключается и настраивается прямо
из панели: вставили токен от [@BotFather](https://t.me/BotFather) — бот заработал.

## Возможности

|  | Что внутри |
|---|---|
| 📊 **Обзор** | Выручка, активные подписки, состояние нод — одним взглядом |
| 🖥️ **Ноды** | Список нод Remnawave, онлайн/офлайн, трафик, включение/отключение/рестарт |
| 👤 **Пользователи** | Поиск, ручная выдача дней, устройства (HWID), бан |
| 🤖 **Бот** | Подключение по токену прямо из панели, тарифы, триал, обычные/премиум эмодзи |
| 💳 **Платежи** | СБП/карта (Platega), крипта (CryptoBot), Telegram Stars, кошелёк |
| 🎟️ **Промокоды и рефералка** | Бонусные дни, скидки, реферальные награды за оплату |
| 📣 **Рассылки** | Текст + фото + кнопки, сегменты аудитории, живой прогресс отправки |
| 📈 **Аналитика** | Выручка и новые пользователи по дням, конверсия из триала, топ тарифов |

## Установка

Ubuntu 22.04+ с правами root:

```bash
git clone https://github.com/valentinvelnesev-alt/vpn-panel vpn-panel && cd vpn-panel
sudo bash install.sh
```

Установщик спросит режим доступа, сгенерирует секреты, поднимет контейнеры и
создаст администратора.

### Два режима доступа

| | Когда выбирать | Адрес панели |
|---|---|---|
| **Домен + HTTPS** | есть домен, A-запись направлена на сервер | `https://panel.example.com` |
| **По IP, HTTP** | домена пока нет | `http://<IP>:4250` |

В режиме по IP трафик не шифруется — закройте порт файрволом:

```bash
ufw allow from <ваш-ip> to any port 4250 proto tcp
```

Появится домен — запустите `install.sh` заново и выберите первый режим,
данные сохранятся.

### После установки

1. Войдите в панель.
2. Укажите адрес и токен Remnawave.
3. На вкладке **Бот** вставьте токен от [@BotFather](https://t.me/BotFather) и нажмите «Запустить».

Токен бота можно поменять в любой момент — панель переключит бота без
перезапуска сервера, база клиентов не теряется (привязка идёт по Telegram ID).

## Устройство проекта

| Сервис | Назначение |
|---|---|
| `panel-api` | FastAPI: REST и WebSocket, миграции при старте |
| `panel-web` | React SPA, собирается в том для Caddy |
| `bot` | aiogram 3, настройки читает из БД |
| `postgres` | данные панели и бота |
| `redis` | FSM бота, кэш метрик, команды панели боту |
| `caddy` | HTTPS/HTTP, раздача SPA и загруженных фото, прокси на API |

```
backend/   FastAPI-приложение, Alembic-миграции, бизнес-логика панели
bot/       aiogram-бот: хендлеры, воркеры (напоминания, рассылки, платежи)
frontend/  React + Vite + Tailwind SPA
shared/    общий код панели и бота: модели БД, клиент Remnawave, платежи
```

Клиент Remnawave генерируется из официальной спеки
`shared/openapi/remnawave-2.8.1.json` — при выходе новой версии панели
Remnawave достаточно заменить файл и перегенерировать клиент.

## Обновление

Если панель уже установлена, обновитесь одной командой:

```bash
cd ~/vpn-panel && curl -fsSL https://raw.githubusercontent.com/valentinvelnesev-alt/vpn-panel/main/update.sh | bash
```

Скрипт автоматически создаст бэкап `.env` и базы данных, подтянет изменения и перезапустит контейнеры. После первого запуска `update.sh` останется в папке — в следующий раз достаточно `bash update.sh`.

## Обслуживание

```bash
docker compose logs -f          # логи
docker compose down             # остановка
```

Файл `.env` содержит пароль БД и ключ шифрования — без него данные
восстановить нельзя. Храните копию отдельно от сервера.
