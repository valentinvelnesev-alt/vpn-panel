# Обновление бота: множественные подписки, встроенная админка, новые способы оплаты

## 🆕 Новое

- **Несколько подписок на одного пользователя.** Раньше при повторной покупке бот продлевал единственный ключ — теперь каждая покупка тарифа заводит отдельный, независимый ключ. Появился раздел **«Мои подписки»**: список всех ключей пользователя, у каждого — своя ссылка для подключения, свои устройства и возможность продлить именно его.
- **«Мой профиль».** Баланс, пополнение кошелька и история покупок собраны в одном месте.
- **Админ-панель прямо в Telegram** — команда `/admin` (доступ настраивается в веб-панели по Telegram ID):
  - 📊 Статистика: пользователи, финансы, рефералы, рассылки, уведомления
  - 📢 Создание рассылки прямо из чата — текст и сегмент аудитории
  - 🎟 Создание и просмотр промокодов без захода в браузер
- **RollyPay** — второй способ оплаты через СБП, включается/выключается в панели.
- **Категории тарифов.** Админ сам создаёт, переименовывает и удаляет любые категории (например «VPN» и «VPN + LTE») — бот показывает их вкладками в меню тарифов.
- **Денежная реферальная программа** — двухуровневая процентная комиссия на баланс с каждой оплаты приглашённого (не только с первой), с настройкой процентов в панели.
- **Уведомления о продажах** в отдельный чат/группу.

## 🛠 Улучшено

- Обновлённое главное меню бота: более понятная структура (Купить подписку / Мои подписки, Мой профиль / Промокод, Пригласить друга).
- Панель обновления `update.sh` — бэкап `.env` и базы данных перед обновлением, показ списка изменений.
- Установка панели: повторный ввод пароля администратора при ошибке вместо остановки скрипта.

## 🐛 Исправлено

- Ошибка 500 в списке пользователей и в создании подписок (триал и оплаченные) — панель была рассинхронизирована с обновлённым API Remnawave.
- Бот иногда не запускался после нажатия «Запустить» в панели — гонка между сохранением настроек и командой запуска.
- Индикатор статуса бота теперь показывает «запускается…» вместо «остановлен» в момент старта.
